# SPK Pemilihan Jalur Pendakian (Weighted Product)

Sistem pendukung keputusan untuk memilih jalur pendakian gunung dengan metode Weighted Product.

- `wp.py`: perhitungan WP (jalankan `python wp.py` untuk self-check)
- `app.py`: tampilan web Streamlit

Jalankan lokal:

```
pip install -r requirements.txt
streamlit run app.py
```

Data jalur di aplikasi adalah data contoh fiktif.
